Single Order Infrastructure Access (SoIA)

Single-Order Infrastructure Access (SoIA) provides a simple, single-order way to access physical infrastructure for virtually any application or location, from street apparatus to commercial premises and data centres. Supporting single-circuit capacities of up to 44 Pbps, with the potential to reach 1 Ebps.

Blown Fibre Access (BFA)

Blown Fibre Access provides dedicated blown-fibre infrastructure between locations, supporting flexible fibre deployment for virtually any application or location, from street apparatus to commercial premises and data centres.

Dark Fibre Access (DFA)

Dark Fibre Access provides dedicated, unlit optical fibre between locations, offering customers complete control over their network design, equipment and transmission capacity.

Optical Wavelength Access (OWA)

Optical Wavelength Access provides high-capacity optical connectivity between locations, delivering dedicated wavelength services for applications requiring reliable, scalable bandwidth.

Ethernet Access (EA)

Ethernet Access provides a range of connectivity options, from aggregated access to dedicated services, across a wide range of available optios.

Aggregated Ethernet Access (AEA)

Aggregated Ethernet Access is a complete Ethernet product supporting multiple connectivity options.

Direct Ethernet Access (DEA)

A dedicated Ethernet service, built to the customer's requirements, providing a direct leased-line connection.

Wireless Ethernet Access (WEA)

Wireless Ethernet Access provides point-to-point or point-to-multipoint Ethernet connectivity over a wireless link.

Datacenter Connect (DCC)

Datacenter Connect provides a range of high capacity connectivity options, suitable for datacenter use.
